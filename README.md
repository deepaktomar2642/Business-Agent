# Business Agent (Minimal Version)

An AI-powered **Business Agent** using LangChain + OpenAI.

## Features
- Book meetings (mock / Google Calendar compatible)
- Update CRM entries
- Create invoices
- Conversational interface via CLI

## Installation
```bash
git clone <repo_url>
cd business-agent
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
